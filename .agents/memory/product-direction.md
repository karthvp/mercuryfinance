---
name: Mercury planning direction
description: User-stated product goals for budgeting, forecasting, and bank reconciliation.
---

The goal is to take the running calendar of expenses and help it plan and forecast budgets more. Plaid is one option so users do not need manual balance updates. Income needs to be reconciled with actual deposits, and outflows matched to actual transactions.

**Why:** The user stated this as the product's intended direction.

**How to apply:** Evaluate new features against better forward-looking budgeting and a trustworthy connection between planned and actual money. Plaid was raised as an option, not a committed provider decision.

Signing in should automatically take users to their dashboard, not back to the homepage.

**Why:** The user explicitly requested this sign-in behavior.

**How to apply:** Keep the dashboard as the successful sign-in destination when changing authentication or app navigation.

The calendar and other parts of the app should open near the current date so users do not need to scroll through old information. Apply that principle throughout the app.

**Why:** The user explicitly requested this as an app-wide behavior.

**How to apply:** Default dated views to today, upcoming plans, or recent actuals as appropriate. Keep older records accessible and respect deliberate month/date selections instead of repeatedly jumping users back to today.
